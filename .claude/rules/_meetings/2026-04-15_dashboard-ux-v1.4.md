## 의제 1 · 현재 3페이지 UX 진단

### P1 UX 리서처
- Home의 Hero + Summary + 강의 목록은 "관리 도구" 성격. 처음 방문한 1인 강사가 "뭘 먼저 해야 하지?"에서 멈춤.
- New는 폼 8항목이 한 화면에 펼쳐져 있어 스크롤 피로. 특히 오디언스·브랜드·입력모드·테마가 동등한 가중치로 배치되어 **중요도 hierarchy 부재**.
- System은 개발자 도구 성격이라 일반 사용자가 길을 잃음. Home과 시각적으로 구분되지 않음.
- 핵심 지적: **진입 후 3초 안에 "내가 할 행동"이 보이지 않음.**

### P2 시각 디자이너
- 파자마보스 팔레트(gold/cream/ink)는 잘 지켜졌으나 Home hero와 summary strip 사이 여백 32px 부족 → 덩어리로 읽힘.
- theme-card-grid의 preview.svg 썸네일 비율 제각각. 1픽셀 드리프트는 아니지만 카드 높이 흔들림 있음.
- lecture-card의 진행률 바가 얇아(4px) 색상이 묻힘. gold-soft(#b8941f)로 8px 권장.
- stat-card 4개 동일 가중치 → 핵심 수치("완료 N")가 부각되지 않음.

### P3 프론트엔드 엔지니어
- 3단계 마법사 구현 난이도: Home renderHome을 WizardStep 컴포넌트 3개로 분할하면 되는 구조. 현재 Vanilla JS + `h()` helper로 충분히 수용 가능.
- 로컬 상태는 sessionStorage에 draft 저장 권장. 새로고침 시 복구.
- 테마 카드 preview.svg는 이미 `<link>` 방식이라 경량. 업로드 UI만 추가 필요.
- 접근성: 현 체크박스·input에 `<label for>` 누락 다수.

### P4 프로덕트 매니저
- 핵심 사용 시나리오 우선순위:
  1. **신규 강의 생성** (처음 방문자 80%가 하는 행동) — New 페이지
  2. **진행 중 강의 재진입** (재방문자) — Home 목록
  3. 시스템 점검 (개발자·QA) — System
- 현재 Home은 (2) 중심으로 설계됨. 신규 사용자(1)는 "신규 강의 시작" CTA 버튼 하나에 의존 → **과소설계**.
- 사용자의 3단계 마법사 요청은 시나리오 (1)을 정면으로 지원. 수용 방향.
- 다만 Home을 통째로 마법사로 바꾸면 시나리오 (2) 훼손 → **"대시보드 탭 + 마법사 탭" 듀얼 뷰** 제안.

### P5 1인 강사 페르소나 대표
- 실제 내가 처음 이 화면 보면: "콘텐츠 어디에 올려야 하지?", "브랜드 로고는 어디 넣지?" 두 질문이 먼저.
- New 페이지 폼은 용어가 기술적(slug·parts·input mode). slug가 뭔지 모름.
- 테마는 preview.svg 보면 바로 이해. 좋음. 근데 5개 중 뭐가 기본인지 표시 없음.
- 3단계 마법사: **매우 환영**. 단, 2단계(브랜드 에셋)는 선택적으로 스킵할 수 있어야 함 (처음엔 브랜드 없이 시작하고 싶음).
- 각 단계에 예시 이미지 1개씩 보여주면 좋겠음.

### P6 QA/접근성 전문가
- WCAG AA 기준 현재 통과: 색상 대비 OK. 
- 미통과: 
  - form input `aria-label` 누락
  - 테마 카드 선택 상태 `aria-selected` 없음
  - Hero CTA 버튼이 `<a>`인지 `<button>`인지 혼재
  - 키보드 Tab 순서가 시각 순서와 일치하지 않음 (theme-card-grid에서)
  - SSE 로그 pane이 스크린리더에 노출되지 않음 (`aria-live="polite"` 필요)
- 3단계 마법사 도입 시 각 step `role="tabpanel"` + 진행 표시 `aria-current="step"` 필수.

## 의제 2 · 3단계 마법사 요청 검토

### 사용자 요청 원문
"홈 화면을 3단계 마법사(1. 콘텐츠 업로드/링크 → 2. 브랜드 에셋 업로드 → 3. 테마 선택)로 바꾸고, 3개 모두 선택 시 '강의 만들기' 버튼 활성화"

### 합의 (6인 전원)
**수정 수용**. Home 전체 교체가 아닌 **"Home 상단 마법사 + 하단 강의 목록"** 하이브리드로 재설계.

근거:
- P4: 시나리오 (2) 재진입 경로 보존 필수
- P5: 사용자 기대와 부합 (마법사 + "기존 강의" 둘 다 필요)
- P1: 신규 사용자는 마법사에 시선 집중 (스크롤 전 화면), 재방문자는 스크롤해서 강의 목록 접근
- P3: 구현 비용 낮음 (renderHome에 WizardBlock + LectureListBlock 2개 섹션)

### 세부 조정
- 2단계 브랜드 에셋은 **"나중에 설정" 허용**. 스킵 시 `_default/` 브랜드 자동 사용 (기존 brand-context.md 폴백 정책과 일치).
- 각 단계에 미니 프리뷰 1개 (업로드된 파일명 / 선택된 테마 썸네일).
- 3단계 완료 시 "강의 만들기" 버튼이 New 페이지로 이동하되, 마법사 입력값을 query string/sessionStorage로 전달하여 New 폼 자동 채움.
- 마법사는 1단계부터만 시작 가능 (상단 3개 동시 클릭 가능한 chip 형태 X). 선형 진행이 인지부하 낮음 (P1).

## 의제 3 · Home 개선안

### 필수 (P0/P1)
1. 상단 3단계 마법사 블록 신설 (WizardBlock)
2. Summary strip 간격 확대 + 주요 stat(완료) 강조 크기 up
3. lecture-card 진행률 바 8px · gold-soft 적용
4. 모든 CTA `<button>` 통일 + aria-label
5. empty-state를 마법사 1단계로 대체 (강의 0개면 마법사만 보임)

### 권장 (P2)
6. lecture-card hover 시 "이어서 작업" 빠른 액션 표시
7. 최근 활동 feed (최근 생성/수정 강의 Top 3)
8. 다크/라이트 관계없이 `prefers-reduced-motion` 시 마법사 애니메이션 비활성

---

## 의제 4 · New 개선안

### 필수 (P0/P1)
1. 폼을 **섹션 3개로 재그룹**: (a) 기본 정보(slug·parts·input mode) (b) 오디언스·브랜드 (c) 테마·옵션
2. slug 필드 옆 `?` 툴팁 ("URL 폴더명, 영문 소문자+하이픈")
3. 테마 카드 "기본" 배지 (pajamaboss)
4. 모든 `<input>`에 `<label for>` 연결
5. Exec 비활성 경고 박스를 상단 sticky로 이동 (하단에 있어 놓침)

### 권장 (P2)
6. 마법사에서 넘어온 데이터 자동 채움 + "마법사에서 설정한 값" 시각 표시
7. 비용 프리뷰에 "예상 토큰·시간" 2줄 추가
8. 실행 후 SSE 로그에 `aria-live="polite"` + 최근 10줄 요약 섹션

## 의제 5 · System 개선안

### 필수 (P0)
1. System 페이지에 "개발자 도구" 명시 서브타이틀 (일반 사용자 혼선 방지)
2. Lint 4종을 "상태 요약" 상단 카드로 모아 1줄 표시 (통과/실패 4/4 형태)
3. 비용 계산기를 별도 섹션 아코디언으로 접기 (기본 닫힘)

### 권장 (P1)
4. 브랜드 목록·테마 갤러리에 "새로 추가" 안내 링크 (init-brand 명령어 안내)
5. Smoke Test 실행 중 진행률 시각화
