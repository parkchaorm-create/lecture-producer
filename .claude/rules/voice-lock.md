# Voice Lock (톤 잠금 규약)

> 1강 완성 후 톤을 자동 측정·잠금하여 2~N강에서 일관성 강제.

## 목적

사용자가 "1강 좋다"고 승인한 순간의 톤을 수치화해 잠가둠. 이후 강의는 이 기준을 크게 벗어나면 경고·재작성.

## 생성 시점

1강 스크립트 완성 + H1 게이트(G1-Script) **승인** 직후 자동 생성.

## 2~N강 검증

각 강 작성 후 `voice-lock`과 비교:
- 지표 이탈률 ≤20% 허용
- 초과 시 경고 + 사용자에게 "톤이 달라졌습니다. 재작성할까요?" 질의

## 갱신

사용자가 명시적으로 요청하거나 H1 재게이트 발동 시 재생성. 자동 갱신은 금지 (드리프트 방지).
