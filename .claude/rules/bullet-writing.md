# Bullet Writing Rules (불릿 작성 규칙)

> 모든 bullet-text와 bullet-detail은 이 규칙을 따른다. `bullet-writer` 에이전트의 필수 참조 문서.

## <section id="pattern"> bullet-text 규칙

### 패턴 (필수)
```
{이모지} {키워드} · {핵심 설명}
```

- 예: `🎻 이론 선생 vs 실전 악단 · 차이 완벽 이해`
- 예: `💳 Free / Pro / Max · 어떤 플랜이 내 돈값?`
- 예: `🚕 토큰 · 택시 미터기 원리 + 절약 꿀팁 3가지`

### 문자 수
- **20~30자** (이모지 포함, 공백 제외 기준)
- 10자 이하는 너무 간결, 35자 이상은 초과
- 한국어 1자 = 1카운트

### 정규표현식 검증
```regex
^[\p{Emoji}]+\s[^·]+\s·\s.+$
```
- 첫 문자: 이모지
- 이모지 뒤: 공백 + 키워드
- 중간: ` · ` (공백-중점-공백)
- 뒤: 핵심 설명

### 승인 패턴
- ✓ 이모지가 내용과 연관됨 (🎻 = 바이올린/음악 관련, 🚕 = 택시/이동)
- ✓ 키워드는 주제어 (명사) 위주
- ✓ 핵심은 짧은 동사구 또는 비교 구문

### 금지 패턴
- ✗ 이모지 여러 개 연속 (`🎻🎵`)
- ✗ 이모지 없이 시작
- ✗ `·` 없이 작성
- ✗ 전체 문장 형식 (`이것은 중요합니다`)
- ✗ 마크다운 (`**bold**`, `[link]()`)
- ✗ HTML 태그

## bullet-detail 규칙

### 패턴
- **1~2문장**, 구어체
- 스크립트 원문에 **근거가 있는 내용**만 작성 (날조 금지)
- `bullet-text`를 부연 설명하되 **중복 아님** (확장)

### 문자 수
- 40~120자 권장
- 150자 초과 시 두 문장으로 분할

### 구어체 vs 문어체 (명시적 예시)
- ✓ `"ChatGPT는 음악 이론 선생님 — '이렇게 하세요' 설명만."` (구어체)
- ✗ `"ChatGPT는 음악 이론을 설명만 합니다."` (문어체, 금지)
- ✓ `"꽉 차면 아래 악보부터 소실돼요."` (구어체, 어미 `-요`)
- ✗ `"가득 차면 아래 악보부터 소실됩니다."` (문어체, `-니다`)

### 금지
- 추측/날조 금지 (원문에 없는 사실)
- 표현의 강도 변경 금지 (원문 "약간 느림" → "매우 느림" ✗)
- 자기지칭 (`저는`, `제가`) 원문에 있을 때만 유지
- DEMO 섹션 내용 포함 금지 (PPT에서 제외)

## section-title 규칙

### 패턴
```
{키워드} · {서브키워드}
```
- 예: `토큰 · 택시 미터기`
- 예: `Plan Mode · 왜 필요한가?`

### 문자 수
- **15자 내외** (공백 포함)

### 금지
- 이모지 사용 금지 (title에는 텍스트만)
- 마크다운 금지

## Part-01 기준 Few-shot (골드 스탠다드)

레퍼런스: `ppt_parts/part-01.html` (또는 `input/reference-ppt/*.html`) 슬라이드 3

```
section-title: "18분 · 클로드 코드 정체 + 요금제"

bullet-text 1: "🎻 이론 선생 vs 실전 악단 · 차이 완벽 이해"
bullet-detail 1: "ChatGPT는 음악 이론 선생님 — '이렇게 하세요' 설명만. Claude Code는 직접 연주하는 악단 — 파일 생성·스캔·저장까지 실행합니다."

bullet-text 2: "💳 Free / Pro / Max · 어떤 플랜이 내 돈값?"
bullet-detail 2: "Free=견학만(Claude Code 사용 불가), Pro=$20/월=왕초보 추천, Max=$25~100/월=헤비유저용. 결론: Pro로 시작하세요."

bullet-text 3: "🚕 토큰 · 택시 미터기 원리 + 절약 꿀팁 3가지"
bullet-detail 3: "대화 길수록 미터기 상승. 꿀팁: ① /clear로 리셋 ② 작업별 새 세션 ③ 가벼운 작업은 Haiku 모델(경차 택시)."
```

## 어조와 톤 (일관성)

- **친근한 구어체**: 어미 `-요`, `-죠`, `-거든요`
- **은유/비유 적극 활용**: 오케스트라, 음악, 택시, 레스토랑, 극장 등 청중 친숙 개념
- **숫자와 비교**: "4~5시간 vs 5분", "10개 중 8개", "80% 제거"
- **대비 구조**: `A vs B`, `~이 아니라 ~입니다`, `Before → After`

## 검증

- 정규표현식으로 bullet-text 패턴 자동 검사
- 문자 수 자동 카운트 (20~30자 이탈 경고)
- 금지 패턴 grep (`**`, `[]()`)
- 원문 근거 확인 (bullet-detail의 주요 구절이 스크립트에 존재하는지 대조)
