Cinema Studio 3.5란?

힉스필드의 가장 정교한 영상 연출 도구입니다. 단순히 영상을 생성하는 것을 넘어, 실제 촬영 현장처럼 카메라를 제어할 수 있습니다.

  • 광학 물리 시뮬레이션 — 실제 카메라처럼 초점거리·조리개·심도 제어
  • @태그 시스템 — 캐릭터·로케이션·프롭을 등록해 재사용
  • Mr. Higgs — AI 샷 브레이크다운 어시스턴트
  • 장르 기반 모션 로직 — action·drama·horror·comedy·spectacle

@태그 시스템 사용법

@태그란?

한 번 등록한 캐릭터·배경·소품을 @이름으로 불러와 어느 씬에서든 재사용할 수 있는 시스템입니다.
매번 같은 설명을 타이핑하지 않아도 되고, 일관성도 유지됩니다.

  1. 1
    캐릭터 등록

    AI Influencer(Day 2)에서 만든 인물을 Cinema Studio → 캐릭터 라이브러리에 @이름으로 등록

  2. 2
    로케이션 등록

    Soul Location 또는 직접 만든 배경 이미지를 @로케이션으로 등록

  3. 3
    프롬프트에서 호출

    Cinema Studio 프롬프트 입력창에 @[캐릭터명], @[로케이션명]을 입력하면 해당 에셋이 자동 적용

  4. 4
    장르 + 카메라 설정 추가

    장르를 선택하고 카메라 움직임(push in, pan, orbit 등)을 프롬프트에 명시

💡

@태그가 인식되려면 캐릭터·로케이션이 먼저 라이브러리에 저장되어 있어야 합니다. 등록 전에 @를 쓰면 일반 텍스트로 처리됩니다.

Mr. Higgs · AI 샷 브레이크다운 어시스턴트

Mr. Higgs가 하는 일

"이 장면을 N컷으로 구성해줘"라고 요청하면 컷 순서·앵글·타이밍·카메라 움직임을 자동으로 제안합니다.
영화 콘티처럼 각 컷의 역할을 설명해주고, 제안 받은 뒤 원하는 컷만 개별 생성하면 됩니다.

  • 요청: "루프탑에서 여자 캐릭터가 등장하는 장면을 5컷으로 구성해줘"
  • Mr. Higgs 제안: 1컷(와이드 드론 진입) → 2컷(미디엄 걸어오는 샷) → 3컷(클로즈업 표정) → 4컷(리버스 도시 배경) → 5컷(아웃로 패닝)
  • 각 컷 설명 클릭 → 해당 컷 파라미터 자동 적용 → Generate
Mr. Higgs 요청 예시 프롬프트
@[내캐릭터]가 @[로케이션]에 등장하는 씬을 5컷으로 구성해줘. 첫 컷은 와이드로 공간을 보여주고, 마지막 컷은 클로즈업으로 마무리. 장르는 drama, 전체 무드는 cinematic and moody.

장르별 모션 로직

Cinema Studio는 장르를 선택하면 해당 장르의 카메라 움직임·편집 리듬·조명 분위기를 자동으로 적용합니다.

Part 3 · virality_predictor

1:00 – 1:20 · 20분

virality_predictor란?

AI가 영상의 바이럴 가능성을 분석해주는 도구입니다. 숏폼을 완성하기 전에 돌려보고, 약한 구간을 고친 뒤 최종 생성하는 방식으로 씁니다.

  • 훅 강도 — 첫 3초가 얼마나 사람을 붙잡는가
  • 리텐션 위험 구간 — 시청자가 이탈할 가능성이 높은 구간
  • 오디언스 반응 예측 — 댓글·공유·저장 예상 패턴
숏폼 초안 완성 → virality_predictor 분석 → 약한 구간 개선 → 재생성 → 최종 제출

언제 씁니까?

단계행동
1. 숏폼 초안 완성클립 배치, 자막, BGM까지 모두 붙인 상태
2. virality_predictor 실행영상 파일 또는 URL 입력 → 분석 요청
3. 점수 확인훅 점수 · 리텐션 위험 구간 · 전체 바이럴 점수
4. 개선점수 낮은 구간 → 더 강한 컷으로 교체 또는 자막 수정
5. 재제출개선된 버전으로 다시 분석 → 점수 향상 확인
MCP · virality_predictor 사용 예시
이 숏폼 영상 virality_predictor로 분석해줘. 훅 강도·리텐션 위험 구간을 알려주고, 점수를 올리기 위한 개선안을 구체적으로 제안해줘. [영상 파일 또는 URL]
💡

virality_predictor는 Apps → Professional → Virality Predictor 에서도 사용할 수 있습니다. 오늘 실습에서 개인 숏폼 완성 후 반드시 1회 실행해보세요.
