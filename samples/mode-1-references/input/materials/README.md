# Materials (참고 자료 폴더)

필요 시 이미지·통계·스크린샷 배치. 비어 있어도 파이프라인 진행 가능.

## 권장 구조
```
materials/
├── images/
│   ├── sample-ig-feed.png
│   └── sample-ig-feed-license.txt
├── data/
│   └── sample-stats.csv
└── ui-captures/            # 실습 도구 UI 캡처 (tutorial-design-pre-flight.md 참조)
    ├── tool-a/
    │   ├── 01-install.png
    │   └── 02-first-run.png
    └── tool-b/
```

## 저작권
각 자료 옆에 `<filename>-license.txt`로 출처·라이선스 명시. 교육용 공정이용 범위 준수.
