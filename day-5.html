강의

Part 1 · Supercomputer란?

0:00 – 0:25 · 25분

Supercomputer = 두뇌를 장착한 힉스필드

Supercomputer는 단순한 이미지·영상 생성기가 아닙니다. 영속 메모리 · 커스텀 스킬 · 24/7 자동화를 갖춘 AI 에이전트입니다.

핵심 컨셉: 원하는 걸 자연어로 말하면 — Supercomputer가 스스로 계획을 세우고, 모델·프리셋을 고르고, 완성물까지 만들어냅니다. 제품 하나로 UGC·광고 100가지 변형을 몇 분 안에 뽑아낼 수 있습니다.

  • 영속 메모리 — 내 브랜드 톤·캐릭터·제품을 기억하고 다음 작업에 자동 반영
  • 커스텀 스킬 — 반복 작업을 스킬로 등록 → 명령 하나로 실행
  • 24/7 자동화 — 사람이 클릭하지 않아도 배치로 대량 생성·정렬

Part 2 · 브랜드 런칭 전과정 5단계

0:25 – 1:25 · 60분
① 브랜드 기획 → ② 시장조사 → ③ 런칭 전략 → ④ 광고 소재 → ⑤ 영상
🧭

각 단계마다 무엇을 하는지 → Supercomputer 자연어 명령(복사 버튼) → 참고 영상 → 결과 예시 순으로 봅니다. 모든 명령은 그대로 복사해 Supercomputer 채팅창에 붙여넣으면 됩니다.

단계 ①

브랜드 기획

컨셉·네이밍·톤·로고 방향

무엇을 하나요?

런칭의 토대입니다. Supercomputer에게 카테고리만 주면 브랜드 이름 후보 · 톤앤매너 · 핵심 메시지 · 타깃 · 로고 방향까지 한 번에 정리해줍니다. 이 산출물이 이후 모든 단계(소재·영상)의 영속 메모리 기준이 됩니다.

🎬

참고 영상 — 하나의 프롬프트로 브랜드 전체를 만드는 데모입니다.

Supercomputer · 브랜드 기획 명령
신규 [카테고리] 브랜드를 기획해줘. 다음을 정리해줘: 1) 브랜드 이름 후보 5개 (각각 이유 한 줄) 2) 브랜드 톤앤매너 (3개 키워드 + 설명) 3) 핵심 메시지 / 슬로건 후보 3개 4) 타깃 고객 페르소나 (연령·관심사·구매 동기) 5) 로고 방향 (스타일·색감·심볼 아이디어) 결과를 표로 정리하고, 이후 작업에 이 설정을 기억해줘.
📌

[카테고리]를 본인 아이템으로 교체하세요 (예: 비건 스킨케어, 홈카페 도구, 반려동물 간식).

단계 ②

시장조사

경쟁사·트렌드·타깃 인사이트

무엇을 하나요?

기획한 브랜드가 들어갈 시장을 점검합니다. 경쟁 브랜드 · 시장 트렌드 · 타깃 고객 인사이트를 정리해 "어떤 빈틈을 노릴지" 포지셔닝의 근거를 만듭니다.

🎬

참고 영상 — AI 하나로 마케팅 에이전시급 작업(조사·전략)을 돌리는 데모입니다.

Supercomputer · 시장조사 명령
앞서 기획한 브랜드가 진입할 시장을 조사해줘. 1) 이 카테고리의 주요 경쟁 브랜드 5곳 + 각각의 강점/약점 2) 최근 시장 트렌드 3가지 (소비자가 원하는 방향) 3) 타깃 고객 인사이트 (페인포인트·구매 트리거·자주 보는 채널) 4) 우리 브랜드가 노릴 포지셔닝 빈틈 1~2개 표와 한 줄 요약으로 정리해줘.
단계 ③

런칭 전략

채널·캠페인·콘텐츠 캘린더

무엇을 하나요?

조사 결과를 실행 계획으로 바꿉니다. 채널별 전략 · 캠페인 컨셉 · 4주 콘텐츠 캘린더를 만들어, 무엇을 언제 어디에 올릴지 한눈에 정리합니다.

Supercomputer · 런칭 전략 명령
위 기획·조사 결과를 바탕으로 런칭 전략을 짜줘. 1) 런칭 4주 콘텐츠 캘린더 (주차별 테마 + 요일별 포스트) 2) 채널별 전략 (인스타·틱톡·유튜브 숏폼 — 채널마다 톤/포맷) 3) 런칭 캠페인 컨셉 1개 (해시태그·핵심 비주얼·혜택) 4) 각 콘텐츠에 필요한 소재 종류 (이미지/영상 구분) 주차별 표로 정리해줘.
💡

여기서 나온 "필요한 소재 종류" 목록이 곧바로 ④ 광고 소재 단계의 입력이 됩니다.

단계 ④

광고 소재

키비주얼·UGC·배너 대량 생성

무엇을 하나요?

전략에서 정한 소재를 대량으로 한 번에 생성합니다. 제품컷·UGC 스타일·TV Spot 키비주얼·배너를 브랜드 톤에 맞춰 자동으로 뽑아냅니다. 제품 하나로 수십 개 변형이 가능합니다.

🎬

참고 영상 — MCP + Claude Code로 AI 광고 에이전시를 구성하는 데모입니다.

Supercomputer · 광고 소재 배치 명령
기억한 브랜드 톤으로 이 제품의 광고 이미지 10종을 만들어줘. 구성: - 제품컷 3종 (깔끔한 스튜디오 배경, 다른 앵글) - UGC 스타일 4종 (실사용 느낌, 인물이 제품 사용) - TV Spot 키비주얼 3종 (임팩트 있는 광고 비주얼) 모두 브랜드 색감·톤 유지, 9:16과 1:1 둘 다 뽑아줘.

📌

위 키프레임 이미지는 다음 단계(⑤ 영상)의 첫 프레임으로 그대로 넘어갑니다. 소재와 영상이 끊기지 않고 이어지는 게 오케스트레이션의 핵심입니다.

단계 ⑤

영상

숏폼·광고 영상 자동 생성

무엇을 하나요?

마지막으로 ④의 소재를 움직이는 영상으로 바꿉니다. 9:16 숏폼 여러 편 + 16:9 광고 영상을 한 명령으로 생성합니다. 키프레임·브랜드 톤을 그대로 이어받습니다.

🎬

참고 영상 — 영화·광고·자동화 종합 쇼케이스입니다. 완성 영상의 결과 수준을 확인하세요.

Supercomputer · 영상 생성 명령
위에서 만든 소재로 영상을 만들어줘. - 9:16 숏폼 3편 (각 10~15초, SNS 광고용 — 훅/제품/CTA 구조) - 16:9 광고 영상 1편 (15~20초, 브랜드 무드 강조) 키프레임 이미지를 첫 프레임으로 쓰고, 브랜드 톤·색감을 모든 영상에 통일해줘. 완성되면 가장 바이럴할 순서로 정렬해줘.
💡

5단계를 모두 거치면 — 기획서부터 완성 영상까지 브랜드 런칭 패키지 한 세트가 만들어집니다. 이게 오늘의 최종 산출물입니다.

Part 3 · Claude Code MCP로 Supercomputer 워크플로

1:05 – 1:25 · 20분

자연어로 전 단계를 한 번에 묶기

지금까지의 5단계를 매번 따로 명령하지 않고, Claude Code의 MCP 연결을 통해 하나의 워크플로로 묶어 실행할 수 있습니다. 채팅창에서 "브랜드 런칭 전과정을 돌려줘"라고 말하면 에이전트가 ①~⑤를 순서대로 진행합니다.

  • 폴링(polling) — 영상·이미지 생성에는 시간이 걸립니다. 에이전트가 작업 상태를 주기적으로 확인하며 완료될 때까지 기다립니다.
  • 배치(batch) — 소재 10종, 영상 3편처럼 여러 개를 한 요청으로 묶어 동시에 처리합니다.
Claude Code MCP · 런칭 전과정 한 명령
내 [카테고리] 브랜드 런칭 전과정을 진행해줘. 순서대로: 1) 브랜드 기획서 작성 2) 시장조사 요약 3) 4주 런칭 전략 4) 광고 소재 5종 이상 생성 (배치) 5) 9:16 숏폼 1편 이상 생성 각 단계 결과를 보여주고, 영상은 완료될 때까지 상태를 확인(폴링)해줘.
🔗

MCP 연결·CLI 설정의 상세는 보너스 강의 ⭐ MCP (Day 9)에서 다룹니다. 오늘은 "자연어 한 명령으로 묶을 수 있다"는 개념만 잡으면 충분합니다.

강사 시연 — 가상 브랜드 5단계 런칭

1:25 – 1:30 (도입) · 25분 실연
👀

강사가 가상 브랜드 하나를 실제로 5단계 모두 돌려 보여줍니다. 따라 치지 말고 흐름과 명령의 형태를 눈에 익히세요. 직접 하는 건 바로 이어지는 실습입니다.

  1. 1
    가상 브랜드 설정

    예: "비건 핸드크림 브랜드" → cmd-1(브랜드 기획) 명령 실행 → 이름·톤·메시지 확정

  2. 2
    시장조사 → 전략

    cmd-2 → cmd-3 연속 실행. 경쟁사 표 + 4주 캘린더가 나오는 과정 확인

  3. 3
    광고 소재 배치 생성

    cmd-4 실행 → 제품컷·UGC·키비주얼이 한 번에 나오는 장면 시연

  4. 4
    영상 생성 + 폴링

    cmd-5 실행 → 숏폼·광고 영상 생성. 폴링으로 완료 대기하는 흐름 확인

  5. 5
    패키지 정리

    기획서 + 조사 + 전략 + 소재 + 영상을 한 폴더로 모으는 마무리

내 브랜드 기획

1:30 – 2:00 · 30분

본인이 실제로 런칭하고 싶은(또는 가상의) 브랜드 카테고리를 하나 정하세요. 오늘 4시간 동안 이 브랜드 하나를 끝까지 끌고 갑니다.

  1. 1
    카테고리 결정예: 비건 스킨케어 / 홈카페 도구 / 반려동물 간식 등 하나 선택
  2. 2
    cmd-1 명령 실행

    기억 지시

시장조사 + 런칭 전략

2:00 – 2:40 · 40분

  2. 2

    "우리 브랜드가 노릴 빈틈"을 한 문장으로 메모

  3. 3
