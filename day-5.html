강의

Part 1 · Supercomputer란?

0:00 – 0:25 · 25분

Supercomputer = 두뇌를 장착한 힉스필드

Supercomputer는 단순한 이미지·영상 생성기가 아닙니다. 클라우드 네이티브 자가학습(self-learning) 에이전트입니다. 여러 모델을 오케스트레이션해 기획부터 완성물까지 end-to-end로 실행합니다.

공식 정의 (힉스필드 공식 Supercomputer 튜토리얼):

  • 클라우드 네이티브 자가학습 에이전트 — 내 작업 패턴을 스스로 학습해 다음 작업에 반영
  • 40개+ 내장 도구 — 이미지·영상·리서치·문서 등 작업 도구를 에이전트가 직접 호출
  • 3계층 메모리 — 단기·작업·영속 메모리로 브랜드 톤·캐릭터·제품을 일관되게 유지
  • 모든 모델 오케스트레이션 — 작업마다 최적 모델을 자동 선택해 한 번에 묶어 실행
  • 실제 프레임 분석 — 영상을 텍스트 요약이 아니라 실제 프레임으로 직접 보며 훅·페이싱 파악
  • end-to-end 실행 — 자연어 한 문장으로 계획·모델 선택·완성물까지 한 흐름으로

핵심 컨셉: 원하는 걸 자연어로 말하면 — Supercomputer가 스스로 계획을 세우고, 모델·프리셋을 고르고, 완성물까지 만들어냅니다.

📋

Part 2 · 3가지 대표 워크플로

0:25 – 1:05 · 40분
① Personal Clipper · 긴 영상 → 숏폼  →  ② 1분 스토리 영상 · 아이디어 → 완성 영상  →  ③ 브랜드 캠페인 · 한 문장 → Content Factory
🧭

아래 3가지는 공식 Supercomputer 시연에서 확인된 실제 프롬프트입니다. 각 워크플로마다 무엇을·왜 / 실제 프롬프트(영문 원본 + 한국어 병기) / 동작 방식 / 예상 결과를 봅니다. 모든 프롬프트는 채팅창에 그대로 붙여넣으면 됩니다.

①

Personal Clipper — 긴 영상 → 숏폼

무엇을·왜 하나요?

팟캐스트·인터뷰·라이브 같은 긴 영상에서 베스트 순간만 잘라 9:16 릴스로 만듭니다. 직접 타임라인을 훑으며 컷을 찾는 수고를 없애줍니다. 숏폼 채널을 빠르게 채워야 할 때 가장 자주 쓰는 워크플로입니다.

Supercomputer 채팅 · Personal Clipper (한국어)
이 [영상 링크]에서 베스트 순간들을 찾아 9:16 릴스로 만들어줘. 자동 자막 + 첫 1초 훅 포함.
English (원본) · 영상 링크 붙여넣기
Find the best moments in this podcast and turn them into 9:16 reels with auto captions and a hook in the first second.

동작 방식

키워드 매칭이나 무음 구간 컷이 아니라 프레임 단위로 영상을 직접 시청합니다. 장면별 에너지와 훅을 감지해 가장 강한 순간을 골라내고, 9:16 비율로 리프레임 + 자동 자막을 입힌 클립 세트를 만들어냅니다.

✅

예상 결과: 첫 1초 훅 + 자동 자막이 들어간 9:16 릴스 여러 개가 한 번에 나옵니다. 가장 강한 순서로 정렬해 바로 업로드할 수 있습니다.

②

1분 스토리 영상 — 아이디어 → 완성 영상

무엇을·왜 하나요?

한 문장 컨셉만 주면 Supercomputer가 키프레임 → 스토리 컨셉 제안 → 캐릭터·프롭·로케이션 확정 → 15초 클립 생성 → 자동으로 하나로 이어붙이기(stitch)까지 진행해 1분짜리 애니메이션 영상을 완성합니다. 스토리텔링 숏폼을 빠르게 뽑아야 할 때 씁니다.

Supercomputer 채팅 · 1분 스토리 영상 (한국어)
1분짜리 애니메이션 영상 만들어줘 — [컨셉: 예: 행성을 넘나들며 몬스터와 싸우는 히어로].
English (원본)
I want a 1-minute animated video, [a hero fighting monsters from different planets].

동작 방식 — Supercomputer가 진행하는 5단계

  1. 1
    키프레임 먼저 생성

    영상의 핵심 장면을 이미지로 먼저 뽑아 방향을 잡음

  2. 2
    스토리 컨셉 3개 제안

    같은 컨셉을 풀어낼 서로 다른 스토리 방향 3가지를 제시

  3. 3
    사용자가 '컨셉 1' 선택

    마음에 드는 컨셉 하나를 고르면 그 방향으로 확정

  4. 4
    캐릭터 시트·프롭 시트·로케이션 확정

    일관성을 위해 등장 캐릭터·소품·배경을 시트로 고정 (이미지 드래그로 추가 가능)

  5. 5
    15초 클립 생성 → 자동 stitch

    15초 단위 클립들을 만든 뒤 하나의 1분 영상으로 자동으로 이어붙임

✅

예상 결과: 컨셉·캐릭터·배경이 일관되게 유지된 1분짜리 애니메이션 영상 한 편이 자동으로 완성됩니다.

③

브랜드 캠페인 — Content Factory

무엇을·왜 하나요?

한 문장으로 브랜드 전체(이름·로고·제품 사진·소셜 포스트·영상 광고)를 만들고, 이어서 내 브랜드를 학습 → 잘 되는 콘텐츠 리서치 → 내 브랜드용으로 리빌드까지 한 챗에서 끝냅니다. 원래 전문가 5명+, 수천 달러, 수 주가 걸리던 일을 한 챗으로 대체합니다.

원래 (사람·시간·비용)Supercomputer 한 챗
니치 리서치 (애널리스트)✅ 한 챗 안에서
브랜드 아이덴티티 (브랜드 디자이너)✅ 한 챗 안에서
제품 사진 (제품 포토그래퍼)✅ 한 챗 안에서
리스팅·카피 (카피라이터)✅ 한 챗 안에서
영상 광고 (영상 편집자)✅ 한 챗 안에서
유통 전략 (마케팅 전략가)✅ 한 챗 안에서

→ 5명+ 전문가, 수천 달러, 수 주 → 한 챗

프롬프트 1 · 한 문장으로 브랜드 전체 생성

Supercomputer 채팅 · 브랜드 전체 생성 (한국어)
[운동화] 브랜드 전체를 만들어줘 — 이름, 로고, 제품 사진, 소셜 포스트, 영상 광고 3종.
English (원본)
Create a full [sneaker] brand — name, logo, product photos, social posts, and three styles of video ads.

프롬프트 2 · 학습 + 리서치 + 리빌드 (URL 붙여넣기)

Supercomputer 채팅 · 학습·리서치·리빌드 (한국어)
이 [URL]로 내 브랜드를 학습하고, TikTok·Instagram에서 잘 되는 [카테고리] 콘텐츠를 리서치해서 지금 뜨는 포맷을 내 브랜드용으로 다시 만들어줘.
English (원본) · URL 붙여넣기
Learn my brand from this URL, research top performing content on TikTok and Instagram, find what's viral in my niche, and rebuild it for my brand.

동작 방식

한 챗 안에서 니치 리서치 → 브랜드 아이덴티티 → 제품 사진 → 리스팅 → 영상 광고 → 유통 전략까지 순서대로 진행됩니다. 영상·콘텐츠를 실제 프레임으로 분석해 훅·페이싱을 파악하고, 메모리에 저장된 브랜드 톤을 모든 산출물에 자동으로 유지합니다.

🏆

이 ③번 브랜드 캠페인이 마지막 이틀(Day 6~7) 프로젝트의 토대입니다. 오늘은 가상/내 브랜드로 한 바퀴 돌려 흐름을 익히고, Day 6~7에서 본인의 실제 사업으로 깊게 이어갑니다.

✅

예상 결과: 브랜드명·로고·제품 사진·소셜 포스트·영상 광고가 한 세트로 나오고, 리서치 기반으로 리빌드된 콘텐츠 방향까지 한 챗에 정리됩니다.

실습 A

40분

할 일

본인 관심 분야의 긴 영상 링크(팟캐스트·인터뷰·라이브·강연 등) 하나를 골라, Supercomputer 채팅창에 워크플로 ① 프롬프트와 함께 붙여넣고 9:16 숏폼 클립을 뽑아냅니다.

  • 링크 준비 — 길이가 충분한(5분 이상) 영상 링크 1개
  • 실행 — 워크플로 ① 한국어 프롬프트 + 링크 붙여넣기
  • 확인 — 자동 자막 · 첫 1초 훅 · 9:16 비율
✂️

위 워크플로 ① 프롬프트를 복사해 사용하세요. 링크가 인식 안 되면 다른 영상으로 교체해보세요.

🎯 실습 A 체크포인트

  • 긴 영상 링크 1개 준비 + 채팅창에 워크플로 ① 실행
  • 9:16 숏폼 클립 1개 이상 생성됨
  • 자동 자막 + 첫 1초 훅 확인
실습 B

1분 스토리 영상 — 아이디어 → 완성

50분

할 일

내 아이디어 한 줄을 컨셉으로 넣고, Supercomputer가 제안하는 스토리 컨셉 3개 중 하나를 골라 1분짜리 완성 영상까지 끌고 갑니다.

  • 아이디어 한 줄 — 예: "사막에서 보물을 찾는 고양이", "도시를 누비는 배달 로봇"
  • 실행 — 워크플로 ② 한국어 프롬프트에 내 컨셉 넣기
  • 선택 — 제안된 컨셉 3개 중 "컨셉 1"처럼 하나 고르기
  • 완료 — 캐릭터·배경 시트 확정 → 15초 클립 → 자동 stitch
🎬

위 워크플로 ② 프롬프트를 사용하세요. 컨셉 선택 단계에서 "컨셉 1"처럼 명확히 골라야 다음으로 넘어갑니다.

🎯 실습 B 체크포인트

  • 내 아이디어 한 줄로 워크플로 ② 실행
  • 제안된 컨셉 3개 중 하나 선택
  • 캐릭터·배경 시트 확정 → 자동 stitch까지 완료 (1분 영상 1편)
실습 C

브랜드 캠페인 맛보기

Supercomputer 메뉴가 보이지 않음 계정 플랜에 따라 접근 제한이 있을 수 있음. 강사에게 문의하거나, 퀵스타트 버튼(Personal clipper 등)으로 시작
① 영상 링크가 인식되지 않음 공개(public) 영상인지 확인하고, 다른 링크로 교체. 너무 긴 영상은 일부 구간만 지정해 다시 요청
① 클립이 원하는 순간을 못 잡음 "이 영상에서 가장 임팩트 있는 3순간만"처럼 개수·기준을 명시해 재요청
② 스토리 컨셉이 마음에 안 듦 "컨셉을 다시 3개 제안해줘"로 재생성 요청. 컨셉 선택 단계에서 "컨셉 1"처럼 골라야 다음 단계로 넘어감
② 1분 영상이 한 번에 안 나옴 정상입니다. 키프레임 → 컨셉 제안 → 컨셉 선택 → 시트 확정 → 클립 stitch 순으로 단계가 진행됨
② 캐릭터·배경이 클립마다 달라짐 캐릭터 시트·로케이션 시트를 먼저 확정한 뒤 클립 생성. 필요하면 참고 이미지를 드래그해 고정
③ 브랜드가 한 번에 안 만들어짐 이름·로고·제품 사진 등 항목별로 쪼개 순서대로 요청. 결과를 이후 작업의 톤 기준으로 사용
③ 학습할 URL이 없음 / 리서치가 부실함 URL 부분을 빼고 카테고리만 남겨 리서치만 실행. 경쟁사 이름 2~3개를 직접 적으면 품질이 올라감
③ 산출물 톤이 제각각임 "앞서 정한 브랜드 색감·톤을 유지해줘"를 명령에 명시하고, "이 설정을 기억해줘"로 메모리에 고정
영상 생성이 오래 걸림 / 큐에서 대기 중 정상입니다. tasks 큐에서 완료까지 기다림. 너무 길면 클립 수를 줄여 재요청
