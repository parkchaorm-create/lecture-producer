# Mono Editorial Theme

흑백 에디토리얼 라이트 테마. 학술·대학원·저널리즘·문서 중심 교육.

| 토큰 | 값 | 용도 |
|------|----|----|
| `--black` | `#ffffff` | 순백 배경 |
| `--gold` | `#c8102e` | 레드 악센트 (1%) |
| `--cream` | `#0a0a0a` | 순흑 본문 |
| `--muted` | `#6a6a6a` | 중간 회색 |
| `--dim` | `#c0c0c0` | 연회색 |

## 특징
- WCAG **AAA** 목표 (대부분 테마는 AA)
- 포커스 아웃라인 3px (접근성 강화)
- 세리프 폴백 앞세움
- 배경 모드 기본 `VORONOI` (신문 섹션 같은 분할선)
- 타이트 애니메이션 (duration 250·stagger 0.08)

## 적합한 조합
- 오디언스: `public-lecture` (대학 공개강좌) · `online-course` (학술)
- 브랜드: 대학원·저널리즘 스쿨·리서치 랩
