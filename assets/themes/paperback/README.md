# Paperback Theme

종이책 질감의 라이트 테마. 인문학·독서 모임·온라인 교양 강의용.

## 핵심 토큰

| 토큰 | 값 | 용도 |
|------|----|----|
| `--black` | `#f5efdd` | 배경 (오프화이트) |
| `--gold` | `#8e2b3b` | 와인색 악센트 |
| `--cream` | `#2a1a15` | 어두운 본문 |
| `--text` | `#3a2620` | 본문 텍스트 |
| `--muted` | `#8a7566` | 보조 |
| `--dim` | `#c9b896` | 연한 구분선 |

## 적합한 조합
- 오디언스: `online-course` · `public-lecture` (인문학 계열)
- 브랜드: 출판사·독서 커뮤니티·대학원 · 세리프 친화 아이덴티티

## 주의
- **variant: light** — pajamaboss(dark)와 배경 대비가 반대
- 세리프 폴백 우선이라 영문 브랜딩 시 Georgia·Noto Serif KR 영향
- 배경 모드 기본 `WAVES` (파문 효과가 종이 같음)
