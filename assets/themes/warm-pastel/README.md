# Warm Pastel Theme

라이프스타일·힐링 콘텐츠용 부드러운 파스텔 라이트 테마.

| 토큰 | 값 | 용도 |
|------|----|----|
| `--black` | `#faf5ed` | 크림 배경 |
| `--gold` | `#d87b8b` | 블러시 핑크 악센트 |
| `--gold-soft` | `#b85e6e` | 진한 블러시 |
| `--cream` | `#3a4a3d` | 세이지 어두운 본문 |
| `--text` | `#505a50` | 본문 |
| SVG 그린 | `#7a9576` | 세이지 그린 보조 |

## 적합한 조합
- 오디언스: `public-lecture` (여성 창업자·주부 대상) · `online-course` (라이프스타일)
- 브랜드: 살롱·홈베이킹·플라워·웰니스·교육공감
- 배경 모드 기본 `CONSTELLATION` — 은은한 별 분위기
