# Neo-Tech Theme

개발자·테크 채널 타겟 다크 테마. 시안 네온 + 딥 네이비.

| 토큰 | 값 | 용도 |
|------|----|----|
| `--black` | `#0a0e27` | 딥 네이비 배경 |
| `--gold` | `#00d4ff` | 시안 네온 악센트 |
| `--cream` | `#e6f4ff` | 밝은 텍스트 |
| `--text` | `#c9d9e8` | 본문 |
| `--muted` | `#6a8ab0` | 보조 |

## 적합한 조합
- 오디언스: `youtube-longform` (개발 채널) · `online-course` (코딩 강의)
- 브랜드: DevOps 스튜디오·테크 유튜버·AI 부트캠프
- 배경 모드 기본 `NETWORK` — 노드 그래프 분위기
