Part 1 · 영상 생성 기초 이론

0:00 – 0:20 · 20분

AI는 어떻게 영상을 만드나요?

이미지 입력 → 시간 축 프레임 예측 → 프레임 간 보간 → 영상 완성!
💡

이미지가 "앞으로 어떻게 움직일까"를 AI가 예측해서 연속 프레임을 만듭니다. 시작 이미지의 품질과 구도가 영상 품질에 직결됩니다.

크레딧 전략 — 영상은 이미지보다 훨씬 비쌉니다

  • 영상 1편 ≈ 이미지의 10~30배 크레딧 소모
  • 고해상도(4K)·긴 영상일수록 비용 급증
💡

연습은 4초·720p로 먼저 확인 → 마음에 드는 것만 8초·1080p로 재생성.

영상 모델 선택 기준

모델강점언제 쓰나
Seedance 2.0 ← 오늘 인물 일관성, 레퍼런스 구동, 멀티SKU 인물·제품 영상, Day 3 메인
Kling 3.0 멀티샷, 오디오 싱크 시네마틱 연속 컷
Veo 3.1 초현실적 시네마 품질 최고 품질이 필요할 때
Hailuo 자연 물리, 표정 표현 인물 감정 표현
Wan 2.6 실험적, 예술적 스타일 독특한 비주얼
Cinema Studio 3.0 최고급 시네마 Day 4에서 다룸

Part 2 · Seedance 2.0 핵심 파라미터

0:20 – 0:50 · 30분

① 시작 프레임 (Start Frame) 단독 사용

원리

이미지 1장 → AI 모션 예측 → 영상

좋은 Start Frame 조건:

  • 동적인 포즈 — 정지 포즈보다 움직임이 예상되는 이미지
  • 명확한 피사체 — 흐리거나 복잡한 배경은 주의
  • 9:16 세로 비율 — 미리 생성해두면 품질 향상

강사 예시 — Start Frame으로 적합한 이미지 2장

Start Frame 예시 · 여성 루프탑 → 영상 생성 시 예상 동작: 바람에 머리카락이 날리며 도시 뷰를 바라보는 움직임
Start Frame 예시 · 남성 사무실 → 영상 생성 시 예상 동작: 카메라를 향해 자연스럽게 고개를 돌리거나 미소 짓는 움직임

② 시작+끝 프레임 (Start + End Frame)

원리

A 이미지 (시작) → 자연스러운 전환 → B 이미지 (끝)

활용 장면: 제품 언박싱, 장소 이동, 변신/변화 효과

예시 — 선물박스 변화

End Frame 예시 · 선물박스 Start Frame(닫힌 박스) → End Frame(열린 박스)으로 언박싱 영상 생성
🎁 → 🎉

Start: 리본이 묶인 박스
End: 뚜껑이 열리며 내용물 등장
= 언박싱 영상 자동 생성

Start + End Frame 프롬프트 공식
시작 프레임: [원하는 장면 이미지] 끝 프레임: [결과 장면 이미지] 프롬프트: The person [동작 묘사], smooth transition from start to end frame, cinematic motion, photorealistic

③ 멀티샷 (Multishot) — Seedance 2.0

멀티샷이란?

하나의 생성 요청으로 여러 컷/앵글이 자동 연결되는 방식입니다.
같은 인물·장면을 다양한 각도에서 보여줄 때, 또는 짧은 시퀀스 광고를 만들 때 활용합니다.

강사 예시 — 멀티샷 컨셉

멀티샷 컨셉 이미지 한 인물·장면을 다양한 앵글(정면·측면·클로즈업)로 연속 구성

언제 멀티샷을 쓰나요?

  • 한 장면을 다양한 각도로 보여줄 때
  • 짧은 시퀀스 광고 제작
  • 제품 언박싱 → 사용 → 결과 스토리라인
  • 뮤직비디오 스타일 빠른 컷 편집

④ 레퍼런스 구동 (Reference-driven)

유형설명활용
비디오 레퍼런스 기존 영상의 동작·분위기를 참고 특정 댄스·동작 스타일 복제
오디오 레퍼런스 음악 리듬에 맞춰 움직임 생성 뮤직비디오, 비트에 맞는 영상
멀티SKU 여러 제품을 동시에 일관성 있게 생성 브랜드 제품 라인업 영상

⑤ 장르 파라미터

같은 이미지도 장르에 따라 완전히 다른 영상

auto action horror comedy noir drama epic
💡

실습 A에서 같은 이미지 + 장르만 3개 바꿔서 차이를 직접 확인합니다. 장르가 영상의 분위기를 완전히 결정합니다.

Seedance 2.0 최적화 프롬프트 공식

[주체 묘사] + [동작 방향과 속도] + [카메라 움직임] + [감정/분위기] + [기술적 요소]

프롬프트 예시 3가지

예시 1 · 인물 영상용
A stylish young woman on a rooftop, slowly turning her head toward the camera with a confident smile, gentle hair movement in the wind, slow push-in camera move, cinematic warm golden hour light, film grain, 9:16 vertical
예시 2 · 제품 영상용
A premium skincare product bottle on a white marble surface, slow 360-degree rotation revealing all sides, soft studio lighting with subtle reflections, elegant minimal movement, product commercial quality, 9:16 vertical, cinematic
예시 3 · 라이프스타일 영상용
A person enjoying morning coffee at a cozy window seat, soft natural light streaming in, gentle steam rising from the cup, slow zoom-out revealing the peaceful room, warm ambient atmosphere, cinematic film grain, 9:16 vertical

Part 3 · 바이럴 프리셋

0:50 – 1:20 · 30분

프리셋이란?

미리 만들어진 바이럴 톤의 image-to-video 템플릿입니다.
내 캐릭터·인물 이미지를 1장만 넣으면 해당 씬에 자연스럽게 합성됩니다.

🖥️

사용법: 힉스필드 → Presets 메뉴 → 프리셋 선택 → 캐릭터 이미지 1장 업로드 → 생성

바이럴 프리셋 쇼케이스

DRIFT RACING 밤 거리 레이싱 씬에 내 캐릭터가 등장. 스피드감·긴장감 극대화.
SUMMER HAZE 여름 여행 홈무비 감성. 따뜻하고 빈티지한 색감의 라이프스타일 클립.
2000'S PAPARAZZI Y2K 셀럽 파파라치 스타일. 플래시·그레인으로 2000년대 팝스타 분위기.
RED CARPET 한국 레드카펫 방송 장면. 셀럽 포토타임·인터뷰 분위기 완벽 재현.
ENDING FAIRY (K-pop) K-pop 엔딩요정 스타일. 무대 위 스포트라이트·환호 분위기로 완성.
NIGHT VISION 야간 투시경(NVG) 스타일. 초록빛 단색 군사·스릴러 감성으로 시선 집중.
📌

프리셋 팁: 정면·선명·단독 인물 이미지일수록 합성 품질이 높아집니다. Day 2에서 만든 캐릭터 이미지를 사용하세요.

Part 4 · Lip Sync Studio

강의 내 안내 · 20분

Lip Sync란?

캐릭터 이미지 또는 영상에 대사나 노래를 입혀 입모양을 동기화하는 기능입니다.
AI가 오디오를 분석해서 자동으로 입술 움직임을 생성합니다.

항목내용
사용법 Apps 또는 Video 메뉴 → Lip Sync → 이미지/영상 + 오디오 파일 업로드
적합한 이미지 정면 얼굴이 명확히 보이는 이미지 (전체 얼굴 노출 필수)
지원 형식 이미지(JPG/PNG) + 오디오(MP3/WAV)
활용 제품 설명 영상, 캐릭터 대사, AI 인플루언서 발화 영상
⚠️

주의사항: 옆모습·뒷모습·마스크 착용·그룹 사진은 결과 불량. 정면 단독 얼굴이 반드시 필요합니다.

🖥️

Lip Sync는 오디오 파일이 필요해 MCP로 직접 시연 불가합니다.
웹 UI에서 직접 체험 필요: higgsfield.ai → Apps → Lip Sync
