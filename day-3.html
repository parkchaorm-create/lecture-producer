① 영상 연출 문법 — 핵심만 압축

좋은 영상은 "샷·앵글·무빙·컷·사운드"의 조합입니다. 표로 한눈에 익히세요.

요소종류한 줄 핵심
샷 사이즈와이드 · 풀 · 미디엄 · 클로즈업 · ECU와이드(공간) → 클로즈업(감정)으로 좁혀 들어가면 흐름이 산다
앵글아이레벨 · 로우 · 하이 · 버즈아이로우=당당함, 하이=취약함, 아이레벨=중립
무빙팬 · 틸트 · 줌 · 푸시인 · 트래킹프롬프트에 slow push-in처럼 넣으면 AI가 그 움직임을 만든다
컷씬을 이어 시퀀스 구성같은 샷만 반복하면 지루 → 변화를 줘야 시선이 산다
사운드 3층음성 · 음악 · 효과음세 레이어를 겹치면 영상이 입체적이 된다

🔊 사운드 3층 레이어 — 영상의 절반은 소리다

  • 음성 내레이션 · 대사 — 보이스오버, 인물 대사
  • 음악 BGM — 로파이 피아노, 시네마틱 스트링
  • 효과음 앰비언트 · SFX — 새소리, 물 끓는 소리, 키보드 타이핑
📌

시나리오 보드에서 각 씬마다 이 세 가지를 미리 설계합니다. 음악은 처음 잔잔 → 마지막 고조로 짜면 짧은 영상에도 기승전결이 생깁니다.

🎬

컷 시퀀스 예시: 와이드(공간 소개) → 클로즈업(디테일) → 미디엄(동작) → 클로즈업(감정 마무리). 이 4컷이 모이면 한 편의 30초 영상이 됩니다.

② 시나리오 보드란?

시나리오 보드 = 스토리보드 + 프롬프트 기획서

영상을 만들기 전에 "씬별로 무엇을·어떻게 보여주고 들려줄지"를 미리 설계하는 표입니다. 그림 콘티에 AI에게 줄 프롬프트까지 함께 적은 것이 시나리오 보드입니다.

  • 즉흥으로 만들면 씬마다 톤·인물·메시지가 제각각으로 무너집니다.
  • 보드가 있으면 어떤 툴(Seedance·Kling·Veo…)을 쓰든 같은 설계로 일관된 결과를 얻습니다.
  • 오늘 만든 보드는 곧바로 Part 2 Seedance 2.0에서 실제 영상화하는 재료가 됩니다.

왜 Seedance 2.0가 영상화 1순위인가

  • 인물 일관성 — 같은 인물을 여러 컷에 걸쳐 유지 (숏폼·브랜드 영상의 핵심)

  • 멀티샷 · 레퍼런스 구동 · 멀티SKU — 한 번에 여러 컷·제품 라인업까지

① 시작 프레임 (Start Frame) 단독 사용

원리

이미지 1장 → AI 모션 예측 → 영상

좋은 Start Frame 조건:

  • 동적인 포즈 — 정지 포즈보다 움직임이 예상되는 이미지
  • 명확한 피사체 — 흐리거나 복잡한 배경은 주의
  • 9:16 세로 비율 — 미리 생성해두면 품질 향상 (= 시나리오 보드 키프레임)

강사 예시 — Start Frame으로 적합한 이미지 2장

Start Frame 예시 · 여성 루프탑 → 예상 동작: 바람에 머리카락이 날리며 도시 뷰를 바라보는 움직임
Start Frame 예시 · 남성 사무실 → 예상 동작: 카메라를 향해 자연스럽게 고개를 돌리거나 미소 짓는 움직임

③ 멀티샷 (Multishot)

멀티샷이란?

하나의 생성 요청으로 여러 컷/앵글이 자동 연결되는 방식입니다. 같은 인물·장면을 다양한 각도에서 보여주거나, 짧은 시퀀스 광고를 만들 때 활용합니다.

멀티샷 컨셉 이미지 한 인물·장면을 다양한 앵글(정면·측면·클로즈업)로 연속 구성

언제 멀티샷을 쓰나요?

  • 한 장면을 다양한 각도로 보여줄 때
  • 짧은 시퀀스 광고 제작
  • 제품 언박싱 → 사용 → 결과 스토리라인
  • 뮤직비디오 스타일 빠른 컷 편집

실습 A

시나리오 보드 작성 — ChatGPT로 4씬 보드

2:00 – 2:40 · 40분
🖥️

내가 만들 9:16 숏폼 1편의 주제를 정하고, ChatGPT/Claude로 4씬 시나리오 보드를 완성합니다. 여기서 만든 키프레임이 실습 B Seedance의 재료가 됩니다.

  1. 1
    주제 + 4씬 샷 배분

    내 퍼스널 브랜드·취미·제품 중 하나. 와이드 → 클로즈업 흐름으로 4씬 배치 추천:

    • 씬1 익스트림 와이드 (공간·분위기 소개)
    • 씬2 클로즈업 (핵심 디테일)
    • 씬3 미디엄 (인물 동작)
    • 씬4 클로즈업 (감정 마무리)
  2. 2
    메타 프롬프트로 보드 초안 받기

    Part 1의 메타 프롬프트를 복사 → [내 주제]·[톤] 교체 → ChatGPT/Claude에서 4씬 표(샷·연출 / 이미지 / 영상 / 사운드)를 받습니다.

  3. 3
    검토·수정 + 사운드 3층 채우기

    4씬의 조명·색감 키워드가 통일됐는지 확인. 각 씬에 음성/음악/효과음을 채우고, 막히면 "사운드 프롬프트를 AI로 뽑기" 프롬프트 활용.

  4. 4
    키프레임 4장 생성

    보드의 🎨 이미지 프롬프트를 힉스필드 Image(9:16)에 넣어 씬별 키프레임 생성. 모든 씬 프롬프트 끝에 soft warm light, film grain, consistent color grading 같은 공통 스타일 키워드를 붙이면 4장 톤이 맞습니다.

🎯 실습 A 체크리스트

  • 30초 숏폼 주제 한 줄로 확정
  • 4씬 샷·앵글·무빙 배분 (와이드→클로즈업 흐름)
  • ChatGPT/Claude로 4씬 보드 표 받기 + 검토·수정
  • 각 씬 사운드 3층(음성/음악/효과음) 채우기
  • 키프레임 이미지 생성 (최소 2장, 권장 4장) + 톤 통일 확인
