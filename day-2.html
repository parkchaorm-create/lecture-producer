Part 1 · Flux Kontext — 기존 이미지 편집

0:00 – 0:30 · 30분

Flux Kontext가 뭔가요?

이미 만든 이미지를 AI가 이해하고 원하는 부분만 수정하거나 스타일을 완전히 바꾸는 모델입니다.
원본의 구도와 피사체 배치는 최대한 유지하면서, 분위기·색감·배경을 교체할 수 있습니다.

image-to-image vs Flux Kontext — 무엇이 다른가요?

방식동작 원리언제 쓰나
image-to-image 원본 이미지를 참고해서 새로 생성. 원본과 달라질 수 있음 다른 분위기의 이미지가 필요할 때
Flux Kontext ← 오늘 원본의 구조를 유지하면서 지정한 부분만 변경 피사체 동일하게 유지하고 스타일·배경만 바꿀 때
💡

"내가 만든 커피 이미지를 유지하면서 배경만 다크무디로 바꾸고 싶다" → Flux Kontext

사용 방법 — 3단계

  1. 1
    모델 → Flux Kontext 선택Image 메뉴 → 모델 드롭다운에서 Flux Kontext 선택
  2. 2
    원본 이미지 업로드프롬프트창 옆 📎 아이콘 → 변환하고 싶은 이미지 첨부
  3. 3
    프롬프트 입력 — 공식 사용아래 Flux Kontext 프롬프트 공식을 그대로 써서 입력
Keep [유지할 것] exactly the same.  Change [바꿀 것] to [원하는 스타일/내용].

프롬프트 공식 사용 예시

유지할 것바꿀 것완성 프롬프트 예
커피잔과 구도분위기 → 다크 무디Keep the coffee cup and composition exactly the same. Change the overall mood to dark and moody, deep shadows, dramatic noir lighting.
피사체(인물)배경 → 카페Keep the person exactly the same. Change the background to a cozy cafe interior with warm ambient light.
제품과 위치색감 → 빈티지 70sKeep the product placement exactly the same. Change the color grading to vintage 1970s film aesthetic, warm browns and yellows.

Part 3 · Soul ID & AI 인플루언서

0:50 – 1:30 · 40분

Soul ID란?

사진 3~5장을 학습시켜 어디서든 동일한 얼굴로 생성되는 AI 캐릭터 ID입니다.
한 번 학습하면 Soul 2.0, Soul Cinematic, Soul Location 등 모든 툴에서 동일 얼굴 사용 가능합니다.

🤖

Soul ID = 나의 AI 분신. "내가 직접 촬영하지 않아도 어떤 배경·스타일에서도 같은 얼굴의 콘텐츠를 무한히 생성"

AI Influencer Studio 개념도

Soul ID
학습된 얼굴 + Soul Location
배경 + 스타일 프롬프트
의상·무드 → 무한 콘텐츠

Soul 2.0 vs Soul Cinematic — 어떻게 다른가요?

모델특징어울리는 콘텐츠
Soul 2.0 현실적이고 자연스러운 인물. UGC·SNS 감성 패션, 라이프스타일, 뷰티, 인스타 피드
Soul Cinematic 영화적이고 드라마틱한 조명. 강한 분위기 영화 포스터, 브랜드 캠페인, 럭셔리 광고

Soul ID 학습 절차

  1. 1
    AI Influencer 메뉴로 이동 상단 메뉴 → AI Influencer → Soul ID 탭
  2. 2
    사진 3~5장 업로드
    • 정면 촬영, 얼굴이 선명하게 보이는 사진
    • 다양한 각도 (정면 1장 + 측면 1장 + 45도 1장 권장)
    • 배경이 단순할수록 학습 품질 높음
  3. 3
    학습 실행 (5~10분) 업로드 완료 → Train / Create 버튼 클릭 → 5~10분 대기
  4. 4
    학습 완료 → 모든 툴에서 사용 Image → Soul 2.0 또는 Soul Cinematic 모델 선택 → 프롬프트에 Soul ID 불러오기
⚠️

초상권 주의: Soul ID 학습에는 반드시 본인 사진, 동의받은 사진, 또는 가상 캐릭터만 사용하세요. 타인의 사진을 무단으로 사용하면 초상권 침해가 될 수 있습니다.
