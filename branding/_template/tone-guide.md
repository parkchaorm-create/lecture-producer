# Tone Guide — &lt;오디언스 이름&gt;

## R1. 어조
- 어미 통일: (예: `-습니다` / `-요` / 반말+존댓말 혼용)
- 1인칭: (예: `저는` / `제가` / 사용 안 함)
- 2인칭: (예: `여러분` / `당신` / 호칭 없음)

## R2. 금지 표현
- 결과 약속: ❌ "이렇게 하면 무조건 성공"
- 과장: ❌ "혁명적", "완벽한"
- 연령 호명: ❌ "어머님들", "젊은 분들"
- 매체별 금칙어: (해당 오디언스 특수 사항)

## R3. 권장 표현
- 구체 사례 + 출처 인용
- 비유와 은유 (오케스트라·레스토랑·택시 등)
- 대비 구조 ("A가 아니라 B")

## R4. 문장 길이
- 평균 (글자수)
- 1문장 최대 (글자수)

## R5. 전문 용어
- 영어 병기 (예: "토큰(token)") · 첫 등장 시
- 약어는 풀어 쓰기 1회 + 이후 약어

## R6. 호흡 (문단 단위)
- 1문단 = (분량)
- 1강 = (총 분량)

## R7. 출처 표기
- 모든 사실 주장에 `[src:N]` 출처 ID
- N은 `_design/web-cache-*.md`의 인덱스
