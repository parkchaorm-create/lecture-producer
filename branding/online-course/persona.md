# Persona — Online Course

## P1. 나이대·생활 환경
20~50대 직장인·전향자·학생. 평일 저녁·주말 학습. 데스크탑 60%·태블릿 25%·모바일 15%.

## P2. 사전 지식
유료 강의 결제할 정도로 진지함. 관련 도구 1~3개 사용 경험. "체계적 학습"을 원함.

## P3. 동기·목표
- 1차: 자격증·포트폴리오·이직 준비
- 2차: 사이드 프로젝트·창업
- 강의 완강 + 실습 제출 = 학습 완성

## P4. 환경 제약
- 1.25~2배속 시청 일반화 → 정보 밀도 높여도 OK
- 챕터 단위 끊어 학습 (출퇴근 30분 단위)
- 검색·되감기 자주 사용 → 챕터 마커·자막 정확성 중요
- 부교재 없으면 학습 효율 -50% → PDF·코드 동봉 필수
