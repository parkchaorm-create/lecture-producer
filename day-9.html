강의

Part 1 · 왜 Claude 대화 + 힉스필드인가

0:00 – 0:20 · 20분

한 문장으로

Claude(claude.ai)는 프롬프트를 잘 써주는 글쓰기·기획 파트너, 힉스필드는 그 프롬프트로 그림·영상을 뽑아내는 생성 엔진입니다.
둘을 합치면 — 기획·프롬프트는 Claude, 생성은 힉스필드. 코딩은 한 줄도 필요 없습니다.

🤝

비유하면 — Claude는 대본·콘셉트를 짜주는 작가, 힉스필드는 그 대본대로 찍어주는 촬영팀. 작가에게 먼저 말을 잘 시키면 결과물이 달라집니다.

아이디어 → Claude 대화(기획·프롬프트) → 힉스필드(생성) → 다시 Claude에게 "더 ○○하게" → 반복

힉스필드 웹 단독 vs Claude 대화 활용

힉스필드 웹 단독Claude 대화 활용
프롬프트 품질혼자 머리 짜내기Claude가 영어로 다듬어 줌
기획·구성장면을 일일이 직접시나리오·브랜드까지 같이 설계
반복·수정매번 새로 작성"더 밝게 다시" 대화로 미세조정
언어영어 프롬프트 부담한국어로 말하면 영어로 변환
💡

힉스필드 웹을 버리는 게 아닙니다. 프롬프트·기획은 Claude, 실제 생성·미세조정은 힉스필드 — 둘을 짝지어 씁니다.

공식 사례 — Adil도 이렇게 합니다

힉스필드 공식 영상에서 창업자 Adil은 로고·브랜드를 만들 때 "먼저 Claude로 더 좋은 프롬프트를 쓴다"고 말합니다. 좋은 결과물의 절반은 좋은 프롬프트에서 나오기 때문입니다.

🎬

오늘 배우는 방식 A(프롬프트 작성 보조)가 바로 그 방법입니다. 연결 설정조차 필요 없이, 대화창만으로 시작할 수 있습니다.

Part 2 · 방식 A — Claude로 프롬프트 만들기

0:20 – 1:00 · 40분
💬

연결이 필요 없습니다. claude.ai 대화창에 아래 "메타 프롬프트"를 그대로 붙여넣어 보세요. [...] 부분만 본인 내용으로 바꾸면 됩니다. Claude가 만들어 준 프롬프트를 복사해서 힉스필드 웹에 붙여넣어 생성합니다.

Claude에게 "프롬프트 만들어줘" → 받은 프롬프트 복사 → 힉스필드 웹에 붙여넣기 → 생성
① 로고 프롬프트 만들기
패션 브랜드 [브랜드명]용 로고 생성 프롬프트를 영어로 만들어줘. 조건: 플랫 벡터, 미니멀, 액센트 컬러 한 가지, 나이키 체크처럼 기억에 남는 단순한 형태. 힉스필드 이미지 생성에 바로 넣을 수 있게 한 문단으로.
② 제품 광고 이미지 프롬프트 3개
힉스필드 Nano Banana Pro용 9:16 제품 광고 이미지 프롬프트 3개를 영어로 만들어줘. 제품: [제품명]. 무드: [무드: 예 따뜻하고 미니멀]. 각 프롬프트는 서로 다른 구도(히어로 / 사용 장면 / 디테일)로.
③ 영상 모션 프롬프트
힉스필드 Seedance 2.0용 영상 모션 프롬프트를 영어로 만들어줘. 시작 이미지: [이미지 설명]. 원하는 동작: [동작: 예 천천히 줌인하며 제품 회전]. 5초 분량 기준으로.
④ 시나리오 보드 (4씬 표)
30초 [주제] 영상의 4씬 시나리오 보드를 표로 만들어줘. 컬럼: 씬 / 이미지 프롬프트(영어) / 영상 모션 프롬프트(영어) / 사운드 아이디어. 힉스필드에 바로 쓸 수 있게.

워크플로 — 받기 → 붙여넣기 → 반복

  1. 1
    Claude에서 프롬프트 받기위 메타 프롬프트로 영어 프롬프트를 생성받기
  2. 2
    복사 → 힉스필드 웹에 붙여넣기힉스필드 이미지/영상 생성창에 그대로 붙여넣고 생성
  3. 3
    결과 보고 다시 Claude에게"방금 결과가 너무 어두워. 더 밝고 따뜻하게 다시 써줘" → 새 프롬프트 받기
  4. 4
    마음에 들 때까지 반복Claude가 매번 다듬어 주므로 직접 영어 고민 안 해도 됨
반복 수정 — "더 ○○하게 다시" 예시
방금 그 프롬프트로 만든 결과가 [문제: 너무 어둡고 차가움]. 더 [형용사: 밝고 따뜻하고 부드럽게] 느낌이 나도록 프롬프트를 다시 써줘. 영어로.
💡

힉스필드에 붙여넣을 때 프롬프트가 너무 길면 Claude에게 "한 문장으로 줄여줘"라고 다시 요청하세요. 너무 긴 프롬프트는 핵심이 묻힙니다.

Part 3 · 방식 B — claude.ai에 힉스필드 커넥터 연결

1:00 – 1:30 · 30분

커넥터란?

claude.ai 설정에서 힉스필드를 "커넥터"로 한 번 연결해두면, 이제부터 대화창에서 바로 "힉스필드로 이미지 만들어줘"라고 말하면 Claude가 직접 힉스필드를 호출해 결과를 가져옵니다. 복사·붙여넣기 왕복이 사라집니다.

🔗

공식 커넥터 주소: https://mcp.higgsfield.ai/mcp · 공식 안내: higgsfield.ai/mcp

공식 연결 3단계 (claude.ai 웹 또는 데스크톱 앱)

  1. 1
    Settings → Connectorsclaude.ai(웹 또는 데스크톱 앱)에서 설정(Settings) → 커넥터(Connectors) 메뉴로 이동
  2. 2
    커스텀 커넥터 추가이름 Higgsfield, MCP 서버 URL https://mcp.higgsfield.ai/mcp 입력
  3. 3
    Add → Connect → 힉스필드 로그인(OAuth)힉스필드 계정으로 로그인하면 연결 완료. API 키 입력 불필요
🔐

보안: 이 방식은 OAuth 로그인이라 API 키를 직접 만들거나 붙여넣을 일이 없습니다. 비밀번호도 claude.ai가 아니라 힉스필드 로그인 화면에만 입력합니다.

연결 후 — 대화로 바로 생성

아래를 claude.ai 대화창에 그대로 입력해 보세요. [...]만 바꾸면 됩니다.

① 이미지 생성
힉스필드로 9:16 이미지 만들어줘 — [장면: 따뜻한 아침 햇살의 미니멀 홈카페, 나무 테이블 위 김 나는 커피잔].
② 이미지 → 영상
이 이미지를 Kling으로 5초 영상으로 만들어줘. 천천히 줌인하는 카메라로.
③ 연결 확인
힉스필드 크레딧 얼마야?
✅

"현재 크레딧 ○○ 남았습니다" 같은 응답이 오면 커넥터 연결 성공입니다.

❌

"힉스필드를 찾을 수 없음" → 커넥터 미연결. Settings → Connectors에서 URL·OAuth 로그인을 다시 확인하세요.

ℹ️

각주 — 개발자라면 터미널 기반 CLI 연결 방식도 있지만, 이 강의는 코딩 없이 누구나 쓸 수 있는 claude.ai 대화·커넥터 방식만 다룹니다.
