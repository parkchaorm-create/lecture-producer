Part 1 · MCP/CLI란 무엇인가

0:00 – 0:20 · 20분

MCP를 한 문장으로

MCP(Model Context Protocol)는 AI 비서(Claude)에게 외부 도구(힉스필드)를 "연결"해주는 표준 방식입니다.
연결만 해두면, 이제부터 채팅으로 "힉스필드에서 이미지 만들어줘"라고 말하면 Claude가 알아서 힉스필드를 조작합니다.

🔌

비유하면 — 힉스필드 웹사이트는 직접 운전, MCP는 "○○로 가줘"라고 말하면 알아서 운전하는 기사를 옆에 두는 것.

자연어 채팅 → Claude Code → (MCP) → 힉스필드 실행 → 결과 받기

Part 2 · 연결 설정

0:20 – 0:40 · 20분

사전 준비

  • Claude Code 설치 — AI 코딩·자동화 도구 (터미널 또는 데스크톱)
  • 힉스필드 계정 + 크레딧 — 생성에 크레딧이 소모됨
  • 연결용 토큰/설정값 — 강사 제공 또는 힉스필드 공식 문서 참조
🔐

보안 최우선 — 키·토큰은 절대 채팅이나 코드에 하드코딩하지 마세요. 환경변수 또는 설정 파일(.mcp.json)에만 넣고, 화면 공유·캡처 시 노출되지 않도록 가립니다. 실제 토큰/설정값은 강사 안내 또는 힉스필드 공식 문서를 따르세요.

MCP 연결 방법 — 2가지 중 택1

환경에 맞는 방법을 선택합니다. 둘 중 하나만 해도 됩니다.

  1. 1
    방법 1 · .mcp.json 설정 파일에 등록 프로젝트 폴더의 .mcp.json에 힉스필드 MCP 서버를 추가합니다. 구조는 아래 예시 참고 (실제 토큰·URL은 강사/공식 문서 값으로 교체).
  2. 2
    방법 2 · 플러그인/커넥터로 추가 Claude Code의 커넥터(플러그인) 메뉴에서 힉스필드를 추가하고 안내에 따라 인증합니다. 설정 파일을 직접 편집하지 않아도 됩니다.
  3. 3
    Claude Code 재시작 연결을 인식하려면 Claude Code를 한 번 껐다 켭니다.
  4. 4
    연결 확인 아래 명령을 채팅에 입력 → 잔액 숫자가 응답으로 오면 연결 성공.
.mcp.json 구조 예시 (값은 강사/공식 문서로 교체)
{ "mcpServers": { "higgsfield": { "command": "...", "args": ["..."], "env": { "HIGGSFIELD_TOKEN": "여기에 직접 적지 말 것 — 환경변수 참조" } } } }
연결 확인 명령
힉스필드 잔액 확인해줘
✅

"현재 크레딧 ○○ 남았습니다" 같은 응답이 오면 연결 성공입니다.

❌

"도구를 찾을 수 없음" → MCP 서버 미연결. 재시작·재등록 후 다시 시도. 안 되면 강사 지원.

Part 4 · 배치·워크플로 자동화

1:10 – 1:30 · 20분

배치 생성의 힘 — 30장을 한 번에

이 강의 교재의 수십 장 이미지·영상은 사람이 하나씩 클릭한 게 아니라, "이 목록 전부 생성해줘" 한 번의 명령으로 배치 생성된 것입니다. 30장을 웹에서 만들면 30번 반복, MCP는 1번.

워크플로 예시 — 자연어 시나리오

Claude에게 "재료 + 목표"만 주면 여러 단계를 알아서 처리합니다.

워크플로 1 · 제품 사진 → 광고 5컷 자동
제품 사진 1장 줄게. 이걸로 광고용 이미지 5컷(히어로 / 사용 장면 / 디테일 / 라이프스타일 / CTA 여백) 만들어줘. 톤은 일관되게.
워크플로 2 · 시나리오 보드 → 키프레임 전부
시나리오 보드 markdown 줄게. 각 씬을 이미지 프롬프트로 바꿔서 키프레임 전부 생성하고, 다 되면 모아서 보여줘.

작업 상태 폴링 — "다 되면 알려줘"

영상은 보통 60~180초 걸립니다. 기다리는 동안 멈춰있지 않고, Claude가 주기적으로 상태를 확인(폴링)하다가 완료되면 결과를 보여줍니다.

폴링 명령
영상 작업 상태 확인해줘. 다 되면 결과 보여줘.
